Prayer Time Display - Portable Edition

QUICK START:
1. Extract all files
2. Double-click PrayerTimeDisplay.exe

CONTROLS:
- F11: Toggle fullscreen/windowed mode
- Edit config/ files to customize
- Edit data/prayer_times.csv for prayer times

FEATURES:
- Real-time prayer time display
- Hijri calendar integration
- 2-minute silent mode countdown
- Green theme with 12-hour time format
